# SimulAI-RE버전

만든이유: 기존 SimulAI의 Lua INI C++ Python같이 복잡한 구조를 버리고
        Python과 numpy를 사용해서 가상세계엔진을 만드는것 Python과 Numpy에도 안되면 그떄 그 부분만 C++로 이동

## 큰설계
- Python Numpy역할
    1. GUI
    2. 기초 연산(경제, 군사, 정치)
    3. 값 정의(UtilityAI나 GOAP의 가중치)
    4. 모딩스크립트

- C++의 역할(확정은 아님)
    1. Python Numpy써도 매우 무거운 연산 가장 병목 심한거
