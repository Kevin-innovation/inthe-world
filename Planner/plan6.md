- FeedBack기초 골격 만들기

현재 부족한 핵심 Feedback는 3가지입니다.
1. 재고-생산 피드백
    재고 증가 -> 생산 감소
    재고 감소 -> 생산 증가
    현재 생산량이 재고를 고려하지 않습니다.
2. 현금-생산 피드백
    현금 감소 -> 생산 또는 고용 감소
    현금 증가 -> 생산능력 증가
    현재 현금은 이익으로만 변하고 생산에 영향을 주지 않습니다.
3. 수요-생산 피드백
    수요 증가 -> 생산 증가
    수요 감소 -> 생산 감소
    현재 수요는 판매량에만 영향을 주고 생산량은 항상 근로자 수로만 결정됩니다.
